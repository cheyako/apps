Lirnyk

Rephrase selected text in any Mac app with AI.

Lirnyk lives in the macOS menu bar. Select text in any app — Mail, Slack, Notes, a browser — and press a shortcut. Lirnyk sends the text to an AI model through OpenRouter and replaces your selection with the rewritten version. Press ⌘Z to undo it.

What it does

  • Works in any app where you can select, copy and paste text
  • Profiles, each with its own shortcut and prompt. Defaults: Friendly (⌃⌥F), Corporate (⌃⌥H) and Tech (⌃⌥O)
  • Write your own profiles: the prompt controls tone, style and language
  • Choose any model available on OpenRouter
  • Keeps your clipboard: what you copied before is restored afterwards
  • Shows progress next to the cursor; press Esc to cancel

Getting started

  • Requires macOS 14 Sonoma or later
  • Download Lirnyk from GitHub Releases and move it to Applications
  • Allow Accessibility access in System Settings → Privacy & Security → Accessibility. Lirnyk needs it to copy and paste the selection for you
  • Create an API key on OpenRouter and enter it in Lirnyk’s Settings

Frequently asked questions

Where does my text go?

Only the text you select when you press a shortcut is sent, together with the profile’s prompt, to OpenRouter and the model you chose. Lirnyk has no account, no server of its own and no analytics. Your API key is stored in the macOS Keychain.

How much does it cost?

Lirnyk is free. You pay OpenRouter for the AI requests made with your key; short rewrites with small models usually cost a fraction of a cent.

Nothing happens when I press a shortcut.

Check that Lirnyk is allowed under Accessibility in System Settings and that text is selected. If Lirnyk was updated, remove it from the Accessibility list and add it again.

Where is the source code?

On GitHub: cheyako/lirnyk-app.
